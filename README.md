# Список задач

Учебное React-приложение с TanStack Query: загружает задачи из JSONPlaceholder, добавляет их через POST и обновляет статус через PATCH.

## Запуск

```sh
npm install
npm run dev
```

Для проверки проекта:

```sh
npm run lint
npm run build
```

JSONPlaceholder — тестовый API: запросы POST и PATCH отвечают успешно, но изменения не сохраняются на сервере и пропадают после перезагрузки страницы.
